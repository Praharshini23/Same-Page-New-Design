# Same-Page-New-Design
Same Page, New Design is a web design project that transforms an existing webpage into a visually appealing, modern interface while preserving its original content and functionality. It demonstrates improved layout, typography, colors, spacing, responsiveness, and accessibility through a before-and-after comparison.

# Project — Same Page, New Design

A before-and-after redesign exercise on Project brief.

## Files
- `before.html` — deliberately plain baseline page, created without a design skill.
- `after.html` — redesigned responsive version, using the Impeccable design vocabulary and critique principles.
- `DESIGN-COMPARISON` — three major improvements and why they help.
- `DESIGN-CONTEXT` — audience, use cases, personality and constraints used for the design pass.
- `.agents/skills/impeccable/SKILL` — project-local Impeccable skill notes and workflow reference.
- `install-impeccable.sh` — optional command to install the current upstream Impeccable skill into a local agent environment.

## Run
Open either HTML file directly in Chrome, Edge or Firefox. No server, build step, API, login or internet connection is needed for the page itself. The redesigned file uses a Google Fonts import as progressive enhancement; system fonts are the fallback.

## Install the upstream Impeccable skill
From this folder, run:

```bash
bash install-impeccable.sh
```

The script runs the upstream installer `npx impeccable install`. It needs Node.js/npm and an internet connection. The project-local skill notes are included so the design process and decisions remain documented even if the installer is not run on this machine.
